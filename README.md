# たこ先生の8本足会議

悩みや課題をひとこと入力すると、タコのキャラクター「たこ先生」が 8 本の足それぞれ違う視点からアイデアを出してくれる Web アプリです。アイデアの生成には Gemini API を使っています。

ドスパラ主催の AI ハッカソン（テーマ「柔」）で制作しました。

**デモ:** https://mimish0778.github.io/octopus-meeting/

## 機能

- 入力した悩みに対して、8 つの視点からアイデアを 1 つずつ提案（各アイデアにタイトルと 2〜3 文の説明）
- 8 つのアイデアを踏まえた、たこ先生からのひとことまとめ
- 同じ悩みで、別のアイデアを出し直すボタン
- よくある悩みをワンクリックで入力できる例文
- 結果を 1 本ずつ読み上げるような、たこ先生の吹き出しとアニメーション
- BGM（ページを最初にクリックしたときに再生開始）

たこ先生は、少し上から目線で自信たっぷりな口調で答えるキャラクターとして設定しています。

## 8 つの視点

| 足 | 視点 | 考え方 |
| --- | --- | --- |
| 1 本目 | 逆転の発想 | 常識をひっくり返したらどうなるか |
| 2 本目 | 引き算の発想 | やめる、減らすという解決策 |
| 3 本目 | 他人の視点 | まったく違う立場の人ならどうするか |
| 4 本目 | 時間軸をずらす | 5 年後の自分、子どもの頃の自分だったら |
| 5 本目 | 遊び心の発想 | ゲームや遊びにしてしまう方法 |
| 6 本目 | 環境を変える | 場所、道具、仕組みを変える |
| 7 本目 | 小さな一歩 | 今すぐ 5 分でできる最小の行動 |
| 8 本目 | 誰かに頼る | 人や仕組みに任せてしまう |

## 使い方

1. [デモページ](https://mimish0778.github.io/octopus-meeting/) を開きます。
2. 入力欄に悩みや決めたいことを書きます。下の例文ボタンを押すと、例文が入力されます。
3. 「たこ先生に相談する」を押します（入力欄で `Ctrl` + `Enter`、Mac では `Command` + `Enter` でも送信できます）。
4. 8 つのアイデアとまとめが表示されます。別のアイデアがほしいときは「もう一度、別の8本で考えてもらう」を押します。

利用者が API キーを用意する必要はありません。

### ローカルで動かす

```bash
git clone https://github.com/mimish0778/octopus-meeting.git
```

クローンした `index.html` をブラウザで開きます。ビルドは不要です。ローカルで開いた場合も、アイデアの生成は公開中の API プロキシ（後述）にリクエストを送って行います。

## 仕組み

```
ブラウザ（index.html） ──> Cloudflare Workers（API プロキシ） ──> Gemini API
```

- Gemini API への直接アクセスを避けるため、ブラウザは`https://octopus-meeting.mimish0778.workers.dev` に置いた Cloudflare Workers のプロキシにリクエストを送ります。プロキシのコードはこのリポジトリには含まれていません。
- リクエストは Gemini API の `generateContent` と同じ形式で、キャラクター設定と 8 つの視点を指示するシステムプロンプトと、入力された悩みを送ります。
- 応答は JSON（`responseMimeType: "application/json"`）で受け取り、次の形をしています。

  ```json
  {
    "ideas": [
      { "title": "短いキャッチタイトル", "body": "アイデアの説明" }
    ],
    "summary": "たこ先生からのひとことまとめ"
  }
  ```

  `ideas` は視点の順に 8 個並び、画面には先頭から 8 個までを表示します。

- プロキシが 400 または 403 を返したときは API キーの問題、429 のときは混雑か利用上限として、それぞれエラーメッセージを表示します。

## 技術構成

| 項目 | 内容 |
| --- | --- |
| フロントエンド | HTML / CSS / JavaScript（`index.html` 1 ファイル。画像と BGM も埋め込み） |
| AI | Gemini API |
| API プロキシ | Cloudflare Workers |
| フォント | [Yomogi](https://fonts.google.com/specimen/Yomogi)、[Zen Maru Gothic](https://fonts.google.com/specimen/Zen+Maru+Gothic)（Google Fonts） |

## 注意事項

- 入力した悩みの文章は、プロキシを経由して Gemini API に送られます。個人情報など、送りたくない内容は書かないでください。
- アイデアは AI が生成したものです。大事な決断は、ご自身でもよく考えてから行ってください。
