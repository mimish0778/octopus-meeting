# たこ先生の8本足会議

悩みを相談すると、たこ先生が 8 本の足それぞれ違う視点からアイデアを出してくれる Web アプリです。

ドスパラ主催の AI ハッカソン（テーマ「柔」）で制作しました。

## 遊び方

1. `index.html` をブラウザで開く
2. 悩みや課題を入力する（「部屋がすぐ散らかって片付かない」などの例もワンタップで入れられます）
3. 送信ボタンを押す（`Ctrl` / `⌘` + `Enter` でも送信できます）

少し待つと、たこ先生が足を 1 本ずつ伸ばしながらアイデアを話してくれて、最後に一言まとめが付きます。ちょっと上から目線でしゃべりますが、中身はちゃんと役に立つことを言うキャラです。

8 本の足の担当はこうなっています。

| 足 | 視点 |
|---|---|
| 1 本目 | 逆転の発想 — 常識をひっくり返したら？ |
| 2 本目 | 引き算の発想 — やめる・減らす |
| 3 本目 | 他人の視点 — 全然違う立場の人ならどうする？ |
| 4 本目 | 時間軸をずらす — 5 年後の自分、子どもの頃の自分なら |
| 5 本目 | 遊び心 — ゲームや遊びにしてしまう |
| 6 本目 | 環境を変える — 場所・道具・仕組みを変える |
| 7 本目 | 小さな一歩 — 今すぐ 5 分でできること |
| 8 本目 | 誰かに頼る — 人や仕組みに任せる |

画面をクリックすると BGM が流れます。

## しくみ

- フロントエンドは HTML / CSS / JavaScript の 1 ファイル（画像と BGM も埋め込み済み）
- アイデアの生成は Gemini API
- API キーをブラウザに置かないよう、Cloudflare Workers（`octopus-meeting.mimish0778.workers.dev`）を間に挟んでいます

ページからは Gemini の `generateContent` と同じ形式のリクエストを Worker に送り、Worker が API キーを付けて Gemini に転送します。たこ先生のキャラ設定と 8 つの視点はシステムプロンプトに書いてあり、結果は JSON（`ideas` 8 件と `summary`）で受け取って表示しています。

Worker のコードはこのリポジトリには含まれていません。自分の環境で動かす場合は、同じように Gemini へ転送する Worker を用意して、`index.html` 内の URL を書き換えてください。
